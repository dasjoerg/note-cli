Klein. Lokal. Im Terminal.

Deine Notizen.
Direkt im Projekt.

note-cli ist ein einfaches Bash-Tool, mit dem du kurze Notizen im aktuellen Arbeitsverzeichnis speicherst und wiederfindest.

Schnell loslegen ↓ Quellcode ansehen ↗
~/mein-projekt

Weniger Ballast

Ein kleines Tool, das einfach seinen Job macht.

Keine Oberfläche, kein Konto, keine komplizierte Einrichtung. Nur ein Skript für Notizen, die zu deinem Arbeitsordner gehören.

#

Automatisch dedupliziert

Der Inhalt bestimmt den SHA-256-Hash. Derselbe Text landet so immer unter demselben Dateinamen.

⌂

Bleibt bei deinem Projekt

Notizen werden lokal unter .notes/db/ im aktuellen Arbeitsverzeichnis abgelegt.

</>

Einfaches Bash-Skript

Der Quellcode ist ein einzelnes Skript. Du kannst direkt nachsehen, was es tut.

Zwei Befehle

Notiz rein.
Wissen wieder da.

Wechsle in dein Projektverzeichnis und nutze das Skript direkt. Die Notizen bleiben auf deinem Rechner.

note add <text>

Speichert eine Notiz und gibt ihren SHA-256-Hash aus.

note list

Zeigt die gespeicherten Notizen mit Hash und Inhalt an.

In wenigen Sekunden

Direkt ausprobieren.

Repository klonen, Skript ausführbar machen und im Projektordner eine Notiz speichern. Benötigt Bash sowie shasum und awk.

git clone https://github.com/dasjoerg/note-cli.git
cd note-cli
chmod +x note
./note add "Meine erste Notiz"
./note list
